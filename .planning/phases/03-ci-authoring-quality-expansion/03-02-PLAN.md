# Plan 03-02: Naturalness Gate Expansion

## Objective

Expand the authored CI naturalness regression suite so weak, vague, robotic, or fragment-like lines cannot slip into learner-facing output merely because they satisfy slot and vocabulary rules.

## Context

The current intake validator already rejects bootstrap slots, short lines, weak fragments, and vague English renderings. The product risk is regression: future authoring pressure could make slot-valid but unnatural Mandarin look acceptable. This plan should add focused tests first, then adjust validator messages or patterns only if the tests reveal a real gap.

## Tasks

<task id="03-02-1" title="Add fragment regression cases">
Add synthetic authored CI validation tests for weak but mechanically plausible lines such as minimal subject-verb fragments, repeated pronoun/modal fragments, or other patterns that are not useful learner-facing acquisition sentences.
</task>

<task id="03-02-2" title="Add vague English regression cases">
Add synthetic tests proving vague English glosses are rejected when they fail to communicate a natural learner-facing sentence meaning.
</task>

<task id="03-02-3" title="Patch validator only where needed">
If any new test exposes a real validator gap, update `src/ciAuthoringIntake.ts` with a small explicit rule. Do not loosen existing rejection rules and do not add one-off exceptions to make bad lines pass.
</task>

<task id="03-02-4" title="Protect promotion behavior">
Add or strengthen a test proving promotion fails when any authored CI item fails slot, vocabulary, or naturalness validation. Confirm the real authored intake remains accepted or document any newly discovered rejected item.
</task>

## Success Criteria

- Weak fragment-like authored lines are rejected.
- Vague English renderings are rejected.
- Promotion still revalidates before adding authored lines to the stream.
- Real accepted authored input is not silently changed unless the implementation finds an actual quality bug and documents it.
- `npm.cmd test` passes.
